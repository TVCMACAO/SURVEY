# Checklist Operativo - Aplicación Independiente

Aplicación React independiente para gestión de checklist operativo de gestión ambiental.

## Características

- ✅ Funcionalidad offline/online
- ✅ Sincronización automática con backend
- ✅ Validación de chequeos
- ✅ Interfaz moderna y responsive
- ✅ PWA ready

## Instalación

```bash
npm install
```

## Desarrollo

```bash
npm run dev
```

## Build

```bash
npm run build
```

## Estructura

- `src/components/` - Componentes React
- `src/hooks/` - Custom hooks
- `src/utils/` - Utilidades y servicios
- `src/auth.js` - Sistema de autenticación
